# Delivering authored content

## Local drafts

Deliver source files, reading editions, book outlines, source snapshots, and a review note together. Describe which checks ran and which decisions remain unresolved. File creation does not imply upload, installation, publication, or sharing.

## Private personal compendiums

In an authenticated Outset session, open the personal compendium library at `/compendium` and choose **Create or edit compendiums** (`/compendium/edit`). Create a private copy of a published system or use the editor's supported full-system JSON import. Personal authoring requires a complete system; campaign extensions are not accepted there.

Edit the draft, inspect compiler diagnostics, and use **Save version** when ready. Saving creates an immutable personal version and normally adds it to your library. If adding to the library fails after saving, retain the successful version and add that saved source rather than saving another duplicate.

Personal versions remain private to their owner. They are not campaign-installable rules releases, global extension bases, or public Marketplace products. Removing a library selection does not rewrite existing characters.

## Campaign rules

A campaign DM uses the campaign Rules workspace for supported extensions and homebrew. Validation, release publication, installation preview, and installation are distinct steps. Installing a release changes the campaign's active rules only after the supported preview and confirmation flow. Existing sheets retain their adopted definitions; installation does not silently rewrite them.

Use the current editor and live tools for exact artifact formats, permissions, and revision requirements. This repository does not offer an alternate installation API or bypass the current user's permissions.

## Reading editions

Reading editions currently ship as application-bundled content. This guide provides authorship and offline validation, not remote installation or a Marketplace publication command. Retain validated reading files for the supported content-delivery process available to you. Do not claim that importing source JSON also installs the adjacent Markdown reading editions.

The public validator consumes a compiled pack snapshot. Obtain it from an authorized artifact or export surface that exposes compiled packs; not every deployment or export supplies it. If unavailable, explain that source-bound validation is pending. Never manufacture hashes to make a reading document appear admitted.
