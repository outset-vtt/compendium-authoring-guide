# Review source fidelity

Start from the selected SRD 5.2.1 source and your separately identified homebrew. Preserve the base rules while distinguishing deliberate homebrew changes from transcription or formatting repairs. A parser cannot establish that rules are faithful.

1. Retain the original source and an exact compiled snapshot. Never edit the frozen witness to make a comparison pass.
2. Inventory facts, qualifiers, exceptions, table cells, nested features, and actual references before rewriting. Structured metadata can contain facts missing from the description.
3. Repair verified line wrapping, not meaningful paragraph boundaries. For PDFs, inspect each original page, including sidebars and column continuations. A bookmark or a line beginning with a known spell name is not proof of an entry boundary.
4. Reconstruct complete tables. Check each row and cell, repeated headings, empty cells, and units. Retain source procedure numbering across intervening tables.
5. Link only contextual references. A creature's Darkvision trait is not automatically a reference to a spell of the same name. Rejoin wrapped phrases before counting reference occurrences.
6. Compare text and structure. Whole-text equality can hide misplaced headings, swallowed paragraphs, and changed conditional ownership. “After exposure” is not equivalent to “after failing the first save.”
7. Record formatting repairs separately from corrections, unresolved contradictions, and editorial additions. If reconstruction is uncertain, preserve readable source prose and record the gap.
8. Re-review after source changes. Replacing a hash alone is not review.

Use the [Lantern Marsh review record](../examples/lantern-marsh/review.md) as a compact model. It identifies the frozen sources, exact retained facts, deliberate presentation changes, and limitations. Attribution and redistribution rights remain attached to source material; these original examples contain no third-party rules text.

For SRD-based homebrew, review action economy, attack/save conventions, recharge timing, spell metadata, and inherited field identities. Do not carry an unrelated mini-system attribute into an SRD creature. Preserve the SRD source and attribution when adapting its actual text; label original additions separately.
