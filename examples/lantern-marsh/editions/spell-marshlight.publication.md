## Spell Details {#lantern-marsh-marshlight-details}

Marshlight is a **level 1 Illusion** spell.

| Property | Value |
| --- | --- |
| Casting Time | Action |
| Range | 30 feet |
| Components | V, S |
| Duration | 1 minute |

Choose **one visible post within range**. It shines blue, marking a safe route for the duration. The light ends early if the post is submerged. It deals **no damage**.
